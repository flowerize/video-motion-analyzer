# Инструкция по трекингу частиц на зеленом фоне

## Описание проблемы
Приложение Video Motion Analyzer теперь имеет улучшенный алгоритм трекинга, который позволяет эффективно отслеживать движущиеся частицы на зеленом фоне. Основная проблема была в том, что алгоритм трекал сам фон, а не движущиеся объекты на нем.

## Новые возможности
- Использование вычитания фона для выделения движущихся объектов
- Настройка скорости обучения модели фона
- Возможность сброса модели фона
- Непрерывный трекинг нескольких объектов: приложение автоматически поддерживает несколько траекторий, показывая их ID, скорость и актуальные позиции в панели статистики

## Рекомендуемые настройки для трекинга частиц на зеленом фоне

### 1. Основные настройки трекинга
- **Hue диапазон**: 0 - 180 (полный диапазон, чтобы захватить все цвета частиц)
- **Saturation**: 50 - 255 (нижнюю границу можно уменьшить, если частицы имеют низкую насыщенность)
- **Value**: 50 - 255 (нижнюю границу можно уменьшить, если частицы темные)

### 2. Дополнительные настройки
- **Использовать вычитание фона**: Включено (галочка должна быть отмечена)
- **Скорость обучения фона**: 0.01 (рекомендуемое значение, можно регулировать)
  - Увеличьте значение (например, до 0.05), если фон быстро меняется
  - Уменьшите значение (например, до 0.001), если фон стабилен

## Пошаговая инструкция

1. **Запустите приложение**
   ```
   python run.py
   ```

2. **Загрузите видео с зеленым фоном**
   - Нажмите "📁 Открыть видео"
   - Выберите ваш файл видео

3. **Настройте параметры трекинга**
   - В разделе "Дополнительные настройки" убедитесь, что включена галочка "Использовать вычитание фона"
   - Установите "Скорость обучения фона" на 0.01
   - В разделе "Настройки трекинга" установите:
     - Hue: 0 - 180
     - Saturation: 50 - 255
     - Value: 50 - 255

4. **Сбросите модель фона (необязательно)**
   - Нажмите "🔄 Сбросить модель фона", если вы хотите переобучить модель с нуля
   - Это особенно полезно, если первые кадры видео содержат движение, которое вы хотите отслеживать

5. **Начните трекинг**
   - Нажмите "Включить трекинг" в переключателе
   - Нажмите "Применить настройки"
   - Нажмите "▶ Воспроизвести"

6. **Наблюдайте за результатом**
   - Зеленый фон будет игнорироваться
   - Приложение будет отслеживать все движущиеся объекты на фоне
   - Для каждого ID отображаются позиция, скорость и цветовая отметка прямо на видео и в панели статистики

## Непрерывный мульти-трекинг

- Во время воспроизведения новые объекты автоматически получают уникальные ID и добавляются в список активных треков
- Если частица временно пропадает, трек сохраняется несколько кадров (параметр Max missed frames) и продолжает движение после повторного появления
- Панель статистики показывает число активных треков, среднюю/максимальную скорость и краткий список объектов (первые 5)
- Экспорт JSON теперь содержит полный журнал по каждому треку (`tracks`), что упрощает последующий анализ

## Советы по настройке

- Если трекинг не работает должным образом, попробуйте изменить "Скорость обучения фона":
  - Более высокое значение (0.05-0.1) для быстро меняющегося фона
  - Более низкое значение (0.001-0.01) для стабильного фона

- Если отслеживаются нежелательные объекты:
  - Уточните диапазоны HSV для фильтрации по цвету
  - Увеличьте минимальную площадь объекта в настройках (в будущих версиях)

- Если движущиеся объекты не отслеживаются:
  - Убедитесь, что "Использовать вычитание фона" включено
  - Попробуйте сбросить модель фона
  - Проверьте, что объекты действительно движутся (алгоритм вычитания фона работает только с движущимися объектами)

## Принцип работы улучшенного алгоритма

1. **Вычитание фона**: Алгоритм создает модель фона и вычитает ее из каждого кадра, оставляя только движущиеся объекты
2. **Цветовая фильтрация**: Применяется HSV фильтрация для ограничения цветов, которые должны отслеживаться
3. **Комбинация масок**: Результаты вычитания фона и цветовой фильтрации объединяются для получения окончательной маски
4. **Обнаружение объектов**: На основе комбинированной маски находятся контуры и определяется положение объектов
