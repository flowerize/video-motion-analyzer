# Video Motion Analyzer

Программа для автоматизированной регистрации, трекинга и анализа траекторий
цветных микрочастиц (в том числе при броуновском движении) по видео.

Приложение на PyQt6 с ядром обработки на OpenCV/NumPy/SciPy: обнаруживает
частицы, устойчиво сопровождает каждую с присвоением ID, строит траектории и
считает количественные характеристики движения по каждой частице отдельно.

## Возможности

- **Обнаружение частиц** по цвету (HSV) с опциональным вычитанием фона (MOG2)
  и морфологической фильтрацией; координаты — субпиксельный центр масс.
- **Устойчивый трекинг без перескоков**: фильтр Калмана (модель постоянной
  скорости) + глобальное сопоставление венгерским алгоритмом + гейтинг
  (по расстоянию и расстоянию Махаланобиса) + признак внешнего вида (HSV) +
  штраф за смену направления движения.
- **Повторный захват** потерянной частицы и **подавление дублей** треков.
- **ID строго из пула 1..N** (N ≤ 5): сколько частиц отслеживаем — столько ID.
- **Настройка количества отслеживаемых точек** (1–5) и **макс. смещения**
  частицы между кадрами (область удержания).
- **Статистика по каждой частице**: выбор частицы из списка; графики траектории,
  скорости и **СКО** (среднеквадратичного отклонения).
- **Экспорт** данных: CSV (по точкам, с колонкой `TrackID`) и JSON (полный
  журнал по трекам с параметрами обработки).
- Сохранение параметров трекинга в `config.json`.

## Требования

- Python 3.9+
- Зависимости из `requirements.txt`:
  `opencv-python`, `PyQt6`, `Pillow`, `numpy`, `matplotlib`, `scipy`

## Установка и запуск

### Локально

```bash
git clone https://github.com/flowerize/video-motion-analyzer.git
cd video-motion-analyzer

python -m pip install -r requirements.txt
python run.py
```

> На macOS системный `/usr/bin/python3` уже содержит нужные пакеты:
> `/usr/bin/python3 run.py`. Homebrew Python 3.14 может не иметь колёс PyQt6/OpenCV.

### Через виртуальное окружение

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
```

### Docker (GUI через X11/XQuartz)

```bash
docker compose up --build
```

## Как пользоваться

1. **Открыть видео** — кнопка «📁 Открыть видео».
2. **Настроить трекинг** (раздел «Настройки трекинга»):
   - **Кол-во точек** — сколько частиц отслеживать одновременно (1–5);
   - **Макс. смещение** — предельное смещение частицы между кадрами (гейт);
   - диапазоны **HSV** (Hue/Sat/Val) для выделения частиц нужного цвета;
   - «Применить настройки».
3. **Дополнительно**: вычитание фона и скорость обучения модели фона,
   «🔄 Сбросить модель фона».
4. Включить **«Включить трекинг»** и нажать **«▶ Воспроизвести»**.
5. **«🎯 Анализ и графики»** — переключение на результаты. В списке
   **«Статистика частицы»** выбрать ID и смотреть вкладки:
   **Траектория / Скорость / СКО / Статистика**.
6. **«📊 Экспорт данных»** — сохранение CSV и JSON.

### Важно для почти неподвижных частиц

При броуновском движении частицы почти не смещаются, и вычитание фона (MOG2)
может «принять» их за фон и потерять. В этом случае **снимите галочку
«Вычитание фона»** — обнаружение пойдёт по цвету. При необходимости уменьшите
«Макс. смещение» (5–7 px), чтобы жёстче удерживать трек на частице.

## Алгоритм трекинга (кратко)

1. **Детекция**: вычитание фона (опц.) + цветовая сегментация HSV + морфология →
   контуры → координаты центра масс (субпиксельно) + признак внешнего вида.
2. **Предсказание**: фильтр Калмана для каждого трека.
3. **Сопоставление**: венгерский алгоритм (одно-к-одному) с гейтингом по
   расстоянию, Махаланобису и внешнему виду + штраф за смену направления.
4. **Управление треками**: подтверждение новых треков, удержание при пропусках,
   повторный захват, подавление дублей, ID из пула 1..N.
